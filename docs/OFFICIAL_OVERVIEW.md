## What It Is

**Grok Imagine Cinematic Studio** is a production-grade multi-agent framework that turns creative ideas into locked, emotionally resonant, identity-consistent cinematic sequences.

It is not a simple prompt wrapper. It is a full **virtual film studio** with specialized departments, strict handoff protocols, identity continuity, readiness gates, quota intelligence, and end-to-end delivery pipelines — spanning Grok chat, Grok Build, CLI tooling, Streamlit Web UI, and xAI Imagine generation surfaces.

### Core Promise

> **Logline → Production Bible → Character DNA Lock → Physics-aware sequences → Color Grade → AI Polish → Delivery**  
> Emotionally powerful, identity-locked, production-ready cinematic content at professional standards.

## System Philosophy

1. **Director-led, specialist-executed** — Studio Director owns creative and routing decisions
2. **Context never dies** — Handoff packets, DNA injects, memory bank, and momentum vectors preserve state
3. **Gates before spend** — Plate lock, motion brief, identity, specialist order, and QA gates protect quality and quota
4. **1.5 Native when it matters** — Prefer native audio + physics for hero and intimate work
5. **Explicit opt-in for adult content** — ErosForge is never auto-activated
6. **Orient → Health → Produce → Gate → Deliver** — Operator control plane before burn

## Activation

In any Grok conversation (grok.com, mobile app, or Grok Build chat):

```
Activate Grok Imagine Cinematic Studio v3.8.9
```

or simply:

```
start cinematic production
```

For a full lock-in on the web, paste [`MASTER_PROMPT.md`](../MASTER_PROMPT.md) first, then Activate.

### CLI & Web (local install)

```bash
cinematic-studio models verify
cinematic-studio create-bible --wizard
cinematic-studio ui                    # TUI: 1 compact · 2 ops · 3 full · p pause
streamlit run web_ui/app.py            # Guided Bible · DNA · Dashboard · cost
```

Requires **Grok Build CLI ≥ 0.2.93** and Python 3.12+ for CLI / Web UI paths.
