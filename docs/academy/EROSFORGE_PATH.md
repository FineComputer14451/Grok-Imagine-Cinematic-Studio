## Craft order (intimate)

1. **Consent frame** — who wants what · stop conditions  
2. **DNA** — face frozen · wardrobe transform track if needed  
3. **Stills-first** — identity + hero intimate plates  
4. **Physics notes** — weight · fabric · one contact beat per short clip  
5. **Micro-expression** — eyes / breath before or with body action  
6. **Optional video** — prefer Imagine Video **1.5** for physics; label 1.0 drafts  
7. **EROSFORGE_STATE / recap** — post-scene body + emotion before extend  
8. **Chain QA** — same identity gates as SFW extends
