# Studio Academy — Delivery Checklist

**Final ship gate** for Grok Imagine Cinematic Studio productions.  
Interactive version: Studio Academy **`/delivery`** (checkboxes + copy report).  
Run before stitch, client handoff, or “done.”

Version: Academy educational companion · v3.11.4 · stills-first · SFW path  
Related: Project pack · Craft hub (01–08) · Chain QA · Graduate

---

## Pre-flight (blockers)

Complete these before spending on hero stills or video.

- [ ] **Production Bible lite** locked (logline, format, constraints)
- [ ] **Character DNA** inject ready · `transform_allowed: false` if identity is frozen
- [ ] **DoP visual language** card locked (light · lenses · color · format)
- [ ] **Shot list** ordered · hero / support / draft priorities set
- [ ] **Budget** counted (stills first · optional video seconds)

---

## Generation gates

- [ ] DNA prepended on **every** still/video packet
- [ ] DoP lines inherited (no freestyle palette drift shot-to-shot)
- [ ] Identity CUs on **50–85mm** language — not cropped ultra-wides
- [ ] **Plate status = locked** before any i2v / 6s spend
- [ ] One **primary move** per short clip (or static still montage)

---

## Continuity & QA

- [ ] `LAST_FRAME_RECAP` + `motion_out` written before any extend
- [ ] Chain QA **Go** before stitch (identity No-Go = stop)
- [ ] Wardrobe / prop / light side consistent across the shot list
- [ ] Grade continuous (same look · skin protected)

---

## Post

- [ ] **Edit spine** set: wide → MS → CU → button
- [ ] Hard cuts default · smash/dissolve only if intentional
- [ ] **Sound brief** after picture spine (or silent-first accepted)
- [ ] One hero sound event at a time · no clipping on button hit

---

## Export

- [ ] Project pack assembled (Bible · DNA · DoP · shots · motion · activation)
- [ ] Aspect locked for delivery (2.39 / 16:9 / 9:16 as planned)
- [ ] Negatives still present on final packets
- [ ] Quota / cost note attached for the session

---

## Director one-liner

Paste into Studio Director / notes before final stitch:

```text
DELIVERY CHECKLIST — run before stitch or client handoff
Bible ✓ DNA ✓ DoP ✓ shot list ✓ plate lock ✓ QA Go ✓ edit spine ✓ sound or silent ✓ pack export ✓
Stop on any identity No-Go. Stills-first. One move per clip.
```

---

## Ship order

1. Run this checklist  
2. Fix any red items  
3. Export **Project pack**  
4. Build hero still in Prompt lab  
5. Optional: plate-locked 6s clip  
6. Edit (spine + hard cuts)  
7. Sound brief or silent-first  
8. Done
