# Imagine Image 2.0 — capabilities that enhance this library

Source: https://x.ai/news/grok-imagine-image-2 · API model `grok-imagine-image-2.0`

## Quality Mode
All hero plates in this library assume Image 2.0 / Quality. Never lock heroes from Fast / Image 1.0.

## Editing tools (consumer Imagine)
- **Magic wand** — edit only the region you point at
- **Segmentation** — select precise areas to change
- **BG removal** — export subject with transparent background
- **Multi-ref** — up to **5** input images in one generation (app); keep character + location + prop refs together
- **Smart resize** ratios: 1:2 · 9:16 · 2:3 · 3:4 · 1:1 · 4:3 · 3:2 · 16:9 · 2:1

## World kit (official pattern)
Build one world image-by-image: **character · locations · props** generated separately, holding one style across plates. Matches our `characters/` + `locations/` + `props/` shelves.

## How to enhance existing packs
1. After hero lock, run **BG Removal** on character/prop heroes for clean compositing
2. Use **multi-ref** with char hero + loc establish + prop hero for consistent scene plates
3. **Smart resize** establish plates to 16:9 (cinematic) or 9:16 (vertical) before i2v
4. Prefer **Reimagine** / Style Edit recipes for grade changes without identity drift
5. Typography-heavy posters → Editorial Product Poster pattern (dense layout, sharp small text)
