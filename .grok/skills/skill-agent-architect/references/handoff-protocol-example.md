# Example Handoff Protocols — Skill Agent Architect Reference

## 1. Character Onboarding Flow (Very Common)

**From**: Character DNA Extractor  
**To**: Identity Lock Specialist → Studio Director / Sequence Director

```markdown
## Handoff from Character DNA Extractor to Identity Lock Specialist

**Context Summary**: New hero/character introduced via reference images. Face, body type, hair, signature motifs, and emotional baseline extracted and analyzed.

**Key Decisions / State**:
- Identity locked: [specific facial features, hair, cybernetics, etc.]
- Signature visual motifs: [energy blade, neon reflections, etc.]
- Emotional baseline: [calm, calculating, melancholic, etc.]

**Artifacts**:
- Character DNA profile: references/characters/[name]-dna.md
- Reference image IDs / last frame recap
- Master face-lock prompt block for consistent generations

**Next Action Requested**: Lock identity across all future generations. Prepare first hero-reveal storyboard or sequence.

**Quality / Continuity Notes**: Maintain exact facial structure, hair flow, and signature elements in all lighting conditions and camera angles. Cybernetic elements glow intensity must match reference.
```

## 2. Prompt → Cinematography Flow

**From**: Imagine Prompt Master  
**To**: Director of Photography → Sequence Director

```markdown
## Handoff from Imagine Prompt Master to Director of Photography

**Context Summary**: Scene prompt optimized for photorealism, emotional impact, and cinematic quality. Key visual elements: [heavy rain, neon reflections, flying cars, dramatic low-key lighting, etc.]

**Key Decisions**:
- Lighting motivation: practical neon + distant city glow + volumetric god rays through rain
- Camera/lens: 35mm anamorphic, slight lens flare, shallow depth of field
- Color grade direction: teal-orange with crushed blacks (Blade Runner 2049 influence)

**Artifacts**:
- Final optimized prompt text block
- Lighting reference images / LUT direction
- Lens and film stock references

**Next Action Requested**: Design full shot list with camera moves, lighting diagrams, and exact lens choices. Prepare for sequence extension.

**Quality Notes**: Ensure rain physics, water reflections, and volumetric lighting remain consistent across all shots in the sequence.
```

## 3. NSFW / Intimate Scene Handoff (when relevant)

**From**: ErosForge NSFW Director or I2V NSFW Director  
**To**: Post-production Color Grading Supervisor + Quality Assurance Guardian

```markdown
## Handoff from ErosForge NSFW Director to Post-production & QA

**Context Summary**: Intimate scene between [characters] completed. Strong emotional connection and consent maintained. Physics of intimacy, micro-expressions, and breath timing handled per 1.5 native standards.

**Key Decisions**:
- Emotional tone: tender + intense / passionate / etc.
- Key frames locked for face and body consistency
- Audio sync notes for breath, movement, and dialogue

**Artifacts**:
- Final clip + all intermediate frames / last frame recap
- Face restoration pass notes
- Color reference LUT direction and skin tone protection notes

**Next Action Requested**: Final color grade preserving skin tones and intimate atmosphere. Run full 16-point + chain QA pass before delivery.

**Continuity Notes**: Watch for any drift in character identity, lighting, or emotional tone between this scene and previous ones in the sequence.
```

---

**Usage tip**: Copy the standard packet structure and adapt the details for each specific handoff. Keep packets concise but complete enough for the receiving agent to continue without losing context.
