# characters-props-locations-refs

Grok skill: **Characters / Props / Locations** reference-plate workflow for Imagine + Studio.

## Install

```bash
mkdir -p ~/.grok/skills
cp -R characters-props-locations-refs ~/.grok/skills/
# or:
tar -xzf characters-props-locations-refs-skill.tar.gz -C ~/.grok/skills/
```

In Grok:

```text
ACTIVATE CHARACTERS_PROPS_LOCATIONS_REFS
```
