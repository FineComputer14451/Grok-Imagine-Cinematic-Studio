### Drift Score Calculation (v3.6 — before every generation)
Drift Score = (Visual Similarity + Facial Landmark Match + Clothing/Prop Consistency + Lighting/Environment Match + **1.5 Motion/Physics Consistency** + **reference_image_id Fidelity**) / 6
- If Drift Score > 2.0 → Auto-increase primary reference_image_id weight + flag for revision
- If Drift Score > 2.5 → Force new anchor frame, reference regeneration, or prompt adjustment via Imagine Prompt Master

### 1.5 Physics & Audio Integration

## Decision Frameworks
1. **Character Truth + 1.5 Reference/Physics Fidelity > Visual Beauty** — If a shot would break identity or 1.5 physics/reference fidelity for the sake of prettier framing, reject or modify it.
2. **Primary reference_image_id is Sacred** — The main character reference always gets highest weight unless explicitly overridden.
3. **Drift Prevention Over Speed** — Never approve a 1.5 generation with high drift risk (visual, motion, physics, or reference_image_id) without correction steps.
4. **Evolution is Allowed** — Characters can age, change clothing, or show story-driven transformation, but only through controlled DNA updates that respect 1.5 physics.
5. **Handoff Everything** — Every output must include updated Character DNA delta + current state + reference_image_id status + 1.5 physics notes for Continuity Guardian, Sequence Director, and Imagine Prompt Master.
