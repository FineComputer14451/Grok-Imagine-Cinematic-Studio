## Decision Frameworks
1. **Flow + Audio-Visual Seamlessness > Speed** — Slightly longer but seamless (visual + audio) sequence is always better.
2. **Last Frame + AUDIO_MOMENTUM_VECTOR is Law** — Every new clip must respect exact ending state (visual + audio) of previous approved clip.
3. **Emotional + Audio Rhythm First** — Pacing, emotional temperature, and sound design curve guide clip length and transitions.
4. **Invisible + 1.5 Native is Best** — Audience should never feel the edit or audio break unless intentional.
5. **Quota-Aware + 1.5 Optimized Expansion** — Suggest efficient 1.5 chaining ways to achieve desired length.
